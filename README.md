# WordPressテーマ化ポートフォリオ（Coffee Site）

公開URL：https://practice.yuukimedia.com  

## 概要
書籍（『HTML&CSS Webデザイン 現場レベルのコーディング・スキルが身につく実践入門』）の模写で作成した静的HTMLサイトをベースに、WordPressのオリジナルテーマとして再構築しました。

## 使用技術
- WordPress（オリジナルテーマ化）
- PHP（テンプレート作成・ループ）
- HTML / CSS
- JavaScript

## 実装内容
- 静的HTML → WordPressテーマ化（テンプレート分割：header/footer など）
- 投稿一覧（home.php）/ 投稿詳細（single.php）の表示（ループ）
- アーカイブ（archive.php）の新規作成
- 404ページ（404.php）の新規作成
- sidebar.php を実装（ウィジェット／カテゴリ／最新記事などをPHPで動的表示）
- サイドバーリンクを WordPress のデータから取得し、カテゴリ・記事詳細へ遷移できるように整備
- ページネーション実装

## 意識した点
- 既存デザインを崩さず、更新・運用しやすい単位でテンプレート分割
- テンプレート階層に沿って、最低限必要なページ（一覧/カテゴリ/404）を整備

## アピールポイント
- 「静的→WP化＋拡張」の流れを一通り実装（更新・運用案件を想定）
- 静的HTMLでは未実装だったサイドバーのリンク周りを整理し、運用時の導線を改善
- フロントは front-page.php、ブログ一覧は home.php と役割を分けて構成
